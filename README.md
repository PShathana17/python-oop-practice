#  Python OOP - Bank Account System

A simple Python project created to practice **Object-Oriented Programming (OOP)** concepts.

##  Project Description

This project simulates a basic bank account system using Python.

It includes a parent `BankAccount` class and a child `SavingsAccount` class that demonstrates **inheritance**.

##  Concepts Practiced

- Classes and Objects
- `__init__()` constructor
- `self`
- Methods
- Inheritance
- Deposit and Withdrawal
- Input Validation
- Transaction History

##  Features

- Create a bank account
- Display account details
- Deposit money
- Withdraw money
- Check insufficient balance
- Display transaction history
- Identify the account type

##  Example

**Initial Balance:** ₹10,000

**Deposit:** ₹2,000

**Withdrawal:** ₹3,000

**Final Balance:** ₹9,000
